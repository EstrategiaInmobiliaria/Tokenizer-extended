    El prompt que hizo esto

    TITLE: LÆDS® Universe — Relationship Intelligence Engine

GOAL: Create a single, self-contained HTML file (no external libraries, no build step, no assets, fully offline) that simulates a relationship intelligence engine for real estate, NOT a CRM dashboard.

CORE CONCEPT: Model human connections like gravity. Not contacts, but potential energy between them.

1. DATA MODEL (100 synthetic nodes, generated in JS):
- PEOPLE (40): {id, name, type: buyer/seller/investor, budget: 1.5M-15M, zone: Lomas/Angelopolis/Centro/Zavaleta, need: inversion/patrimonio/renta, timing: 0-30 days}
- BROKERS (15): {id, name, specialty, inventory, trust_score: 0.6-0.99}
- PROPERTIES (30): {id, title, price, zone, roi: 6-18%, status}
- COMMUNITIES (15): {id, name: WhatsApp groups, members}

2. PHYSICS ENGINE (Aurelith architecture): a REAL force-directed graph model.
For each pair (A,B): attraction_force = zone_match*0.3 + budget_match*0.3 + timing_match*0.2 + relationship_proximity*0.2; if same community, boost *1.5; if broker has property that matches buyer budget+zone, create high potential energy.
SIMULATION: Verlet integration. Nodes attract/repel based on potential. 60fps in canvas.
METRICS: total_possible_connections = n*(n-1)/2; high_relevance: attraction > 0.75; recommended: top 6 by energy; active_opportunities: high_relevance + timing < 7 days.
VALIDATION: live calculation of the metrics updating as the simulation runs; show energy conservation like Aurelith shows orbital energy.
VISUALIZATION: canvas network, dots + glowing lines, line opacity = attraction_force, zoom/pan, click node to inspect. Pure canvas.

3. DYNAMIC SYSTEM (Engine architecture): all readouts driven by the SAME live model.
LEAD → MATCH ENGINE → SCORE (0-100%), WHY (bullet list), NEXT BEST CONNECTION card, and a "Connection Potential vs Timing" live loop graph. If I move a buyer node, SCORE must recalculate live. Optional WebAudio tone based on match score.

4. INTERACTION (Maestro architecture): HUMAN → SIGNAL → INTERPRETATION → STATE → RESPONSE → NEW SIGNAL.
Click any PERSON → 3 recommended connections with explanation "Te recomiendo conectar A con B porque..."; click WHY → reasoning chain (zone %, budget %, community); click CONNECT → node becomes "active opportunity", metrics update, particle flow from A to B.

5. UI LAYOUT: Top pipeline ATTRACT → CONNECT → MATCH → ACT. Center canvas universe. Left: TODAY metrics. Right: NEXT BEST CONNECTION with match %, WHY expandable, CONNECT button.

6. CONSTRAINTS: one HTML file, all CSS+JS inline, no external libraries, no CDN, no fetch, offline, no build step, requestAnimationFrame, expose model variables (console / debug panel), 100 nodes @ 60fps.

7. DELIGHT: nodes glow on high match, lines animate like gravitational fields, particle flow on CONNECT, system serif for LÆDS®, monospace for metrics, dark universe (#0A0A0B) + gold accent (#C6A96B).
