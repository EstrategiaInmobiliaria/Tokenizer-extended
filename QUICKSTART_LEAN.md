# 🚀 Lean Manufacturing MVP - Inicio Rápido (30 segundos)

## Opción 1: Local (Requiere Python)

```bash
# Instalar
pip install streamlit pandas numpy networkx matplotlib

# Ejecutar
streamlit run lean_streamlit_mvp.py
```

Abre: http://localhost:8501
